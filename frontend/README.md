# SAHAAY — Frontend

React 18 + Vite frontend for the SAHAAY (NHAA 14566) Grievance & Vulnerability Assessment Portal.

---

## Key Modules

- **Multilingual Support**: Real-time switching across 6 languages (EN, HI, MR, TA, BN, TE) and locale-aware Web Speech recognition.
- **Citizen Portal**: Multimodal voice/text grievance submission and docket status tracking.
- **Officer Triage Console (`/operator`)**: Priority queue, SVI risk gauges, longitudinal trend charts, and action workflows.

---

## Running Locally

```bash
# Install dependencies
npm install

# Start development server (Port 5174)
npm run dev

# Production build
npm run build
```
